requires the original auto-pause, zero active lifecycles, aligned exact pin,
failed candidate/run, recomputed canonical profile hash, exact installer hash,
PSADT mode, LocalSystem, expected failure tuple and observed null reputation.
It inserts an exact compatibility block without overwriting prior quarantine
and supersedes only matching queued rows that have never been dispatched.

use this gate before overrides or queue insertion.

five minutes, with compare-and-set protection on control state. Generated
package behavior does not change, so the customer and QA packager pin remains
bc329cb8bfafd8d2af940bdc9f8ccf044ac15146. This is deterministic containment,
not a passing retest. The general queue can resume after containment is proved.
